## 3 design changes (and why)
1. **Clear visual hierarchy & typography scale (hero heading, subheading, CTA, sections):** larger/weighted headline and distinct type sizes guide attention to the café name and primary action first, improving scanability.
2. **Improved layout, spacing, and responsive structure (centered container, cards/grid, consistent padding):** whitespace and grouping separate content into understandable chunks and keep it readable/usable on small screens (phone).
3. **Stronger contrast, color system, and affordances (warm palette, styled CTA button, menu cards):** consistent colors and an obvious button make interactive elements recognizable and improve readability/accessibility.
